# 58Ge's Blog

[博客](https://blog.58ge.gs.cn/)用来展示好玩、新鲜的玩意，和一些个人心得。

漫漫程序路，唯code作伴～

## 技术栈

Next.js（App Router）和 React，文章用 MDX，样式用 Tailwind CSS。评论、搜索这些能力来自 [Pliny](https://github.com/timlrx/pliny)。站点基于 [Tailwind Nextjs Starter Blog](https://github.com/timlrx/tailwind-nextjs-starter-blog)。

## 本地预览
